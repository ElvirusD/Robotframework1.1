# Robot Framework Automation Project

Ce projet contient des tests automatisés réalisés avec Robot Framework.

## Objectif
Automatiser des scénarios de test afin de valider le bon fonctionnement de l'application.

## Technologies utilisées
- Robot Framework
- Python
- GitHub Actions (CI/CD)

## Exécution des tests
Pour lancer les tests en local :

```bash
python -m robot tests
